# Calculadora de Recesso — Portal do Colaborador

Site estático para registrar horas de compensação, acompanhar a meta e exportar apontamentos em CSV.

## Privacidade

Os dados são salvos no `localStorage` do navegador de cada visitante; não são enviados a este repositório. O site não implementa autenticação. Não use dados sensíveis nem senhas reais. Limpar os dados do navegador remove os registros locais.

## Publicação

O workflow em `.github/workflows/pages.yml` prepara a publicação no GitHub Pages quando a fonte Pages estiver configurada como **GitHub Actions** nas configurações do repositório.
